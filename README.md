# Dragondance Viewer

[打开 Dragondance Viewer](https://zhuka4141-cmyk.github.io/fku-rj-viewer/)

这是使用 Three.js 0.169.0 的静态赛车查看器。可在正交投影下切换前视、后视、左视、右视、俯视、仰视和等轴测视角。

- 电脑用左键旋转、滚轮缩放、右键平移。手机用一指旋转、两指缩放和平移。
- 点击「爆炸图」展开部件。点击展开的部件可单独还原，点击「全部还原」可恢复整个模型。展开和还原使用匀速直线动画。
- 点击「绘画」在当前画面加上手绘标注。可选颜色和笔宽，撤销上一笔或清空。绘画暂停镜头操作，退出绘画后标注仍留在屏幕上。点击「截图」可将模型和标注存为同一张 PNG。
- D 切换绘画，Esc 退出绘画，Ctrl/Cmd+Z 撤销，X 切换爆炸图。R 自动旋转，W 线框，G 网格，E 轮廓，0 复位视角，S 截图，F 全屏。

模型位于 `./model/dragondance.glb`，来自 STEP AP214，转换网格的参数为 0.1 mm 和 0.35 rad。GLB 以米存储，界面以毫米显示。2026-11-17 版模型约 3.82 MiB，共 14 个带几何体的部件和 188,330 个三角面。

## 本地预览

在项目目录运行以下命令，浏览器打开 `http://127.0.0.1:8000/`。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

GitHub Pages 从 `main` 分支的根目录发布。
