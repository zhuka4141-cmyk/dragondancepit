# Dragondance Viewer

[打开 Dragondance Viewer](https://zhuka4141-cmyk.github.io/fku-rj-viewer/)

这是使用 Three.js 0.169.0 的静态赛车查看器。可在正交投影下切换前视、后视、左视、右视、俯视、仰视和等轴测视角。

- 电脑用左键旋转、滚轮缩放、右键平移。手机用一指旋转、两指缩放和平移。
- 「爆炸图」提供前翼、后翼、轮子、轮子支撑和 Halo 五组。可单组拆装、全部拆开或复位，也可点击模型上的部件操作对应组。拆解距离为 0–150%，部件沿直线匀速移动。
- 「绘画」的自动模式用触控笔直接画，手指继续旋转和缩放。也可切换到「画笔模式」，用鼠标或手指画在模型表面。支持预设色、自定义色、笔刷大小与透明度、压感、柔边和硬边、整笔橡皮、撤销和重做。
- 涂鸦随部件移动，按模型保存到当前浏览器，也可导入、导出本车型的涂鸦 JSON。「截图」会把当前视角中的涂鸦保存到 PNG。
- D 打开绘画，X 打开爆炸图，Esc 关闭工具面板，Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做。R 自动旋转，W 线框，G 网格，E 轮廓，0 复位视角，S 截图，F 全屏。

模型位于 `./model/dragondance.glb`，来自 STEP AP214，转换网格的参数为 0.1 mm 和 0.35 rad。GLB 以米存储，界面以毫米显示。查看器将前后两对轮子沿源模型已有的间隙分开，共 16 个可选部件，保留 188,330 个三角面。

## 本地预览

在项目目录运行以下命令，浏览器打开 `http://127.0.0.1:8000/`。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

GitHub Pages 从 `main` 分支的根目录发布。
